# Simple Accounting — WinForms & SQL Server

A practical educational desktop application for learning **C#**, **Windows Forms**, **SQL Server**, database connectivity, and CRUD-based business software development.

## Features

- Chart of accounts management
- Journal entry registration
- Basic accounting data management
- Create, read, update, and delete operations
- SQL Server-backed storage
- Windows Forms desktop interface

## Technology Stack

- C#
- .NET Framework
- Windows Forms (WinForms)
- Microsoft SQL Server
- Visual Studio

## What This Project Demonstrates

This repository is aimed at developers who want a small but realistic example of a database-driven Windows desktop application. It demonstrates:

- Connecting a WinForms application to SQL Server
- Working with accounting-oriented data
- Implementing CRUD workflows
- Organizing forms for desktop data entry and management

## Getting Started

### Prerequisites

- Windows
- Visual Studio 2019 or later
- Microsoft SQL Server 2017 or later
- SQL Server Management Studio (recommended)

### Clone the repository

```bash
git clone https://github.com/M-Bakhtiyariha/HesabDari.git
cd HesabDari
```

Open the solution in Visual Studio.

### Database

If the repository includes a database backup or SQL script, restore/run it using SQL Server Management Studio, then update the application's connection string to match your local SQL Server instance.

### Run

Build the solution and press **F5** in Visual Studio.

## Educational Use

This project is intended primarily as a learning resource and starter reference for WinForms and SQL Server development. It can be extended with additional accounting workflows, validation, reporting, architecture improvements, and automated tests.
